# ClauseMirror identity brief

## Product identity

- **Need:** agreements frequently cross languages, while reviewers need proof that material meaning survived translation.
- **GenLayer role:** validators independently fetch both frozen pages and judge semantic equivalence across obligations, permissions, prohibitions, deadlines, amounts, remedies, and exceptions.
- **Stored primitive:** quote-bound findings plus SHA-256 receipts for the exact source and translation pages.
- **Human boundary:** an independent reviewer, distinct from the publisher, controls revision requests and final sign-off.
- **Safety boundary:** this is a semantic evidence audit, not legal advice, translator certification, or an enforceability ruling.

## Interface difference matrix

| Dimension | ClauseMirror | Existing workspace patterns deliberately avoided |
|---|---|---|
| Primary metaphor | Side-by-side manuscript and comparison desk | Dashboard cards, command consoles, kanban boards |
| Navigation | Single evidence folio | Repeated sidebar / tab skeleton |
| Core visual | Stitched bilingual passage pairs | Scores, radial meters, generic charts |
| Color / type | Warm paper, editorial red, serif quotations | Dark neon consoles, blue SaaS panels |
| Main action | Open evidence dossier and run semantic mirror | Generic create / evaluate form |
| Result structure | Exact source quote ↔ exact translation quote | Narrative-only AI result |

## Mechanism difference

ClauseMirror is not a generic truth oracle. Its deterministic contract layer validates URLs, quote presence, document identities, exact receipts, finding schema, role separation, lifecycle transitions, and overall status derivation. Consensus is used only for the semantic equivalence judgment that cannot be reduced to byte comparison.
